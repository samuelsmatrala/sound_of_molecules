# Sound Of Molecules

![The San Juan Mountains are beautiful](/images/sound_of_molecules.png "Sound of Molecules")

## Summary

Sound of molecules is an interactive web experience that lets you select a molecule run quantum calculations, view estimated molecular energies, and hear a generated melody. The browser interface six molecules: H3+, H2, H2+, HeH+, Li+, and H4. The frontend is plain HTML and JavaScript. It uses Python through a host-provided bridge and plays the returned audio using the Web Audio API. 

## How it works
User select a molecule which sound he or she wants to hear. The choice is the selected to python where 2 calculations run. First is molecular calculations and second is music generation

####  Molecular calculations 

The molecular calculation estimates the molecule’s total energy for a fixed arrangement of its atoms using quantum phase estimation (QPE). It does not simulate atoms moving, optimize the molecular geometry, or directly calculate an audible frequency.

Each molecule has a configuration containing its atomic positions, electrical charge, spin, and basis set.
For example, hydrogen (H2) is defined as:
```python
{
    "atom": "H 0.0 0.0 0.0; H 0.0 0.0 0.735",
    "charge": 0,
    "spin": 0,
    "basis": "sto-3g"
}
```
PySCF performs classical electronic-structure calculations to construct the Hamiltonian, the mathematical operator describing the electrons’ energy. It includes:
- Electron kinetic energy.
- Attraction between electrons and nuclei.
- Repulsion between electrons.

The electronic Hamiltonian initially uses fermionic operators, which describe electrons. Quantum circuits instead operate on qubits.
The code converts between these representations using parity mapping:
```
mapper = ParityMapper(num_particles=problem.num_particles)
qubit_op = mapper.map(problem.hamiltonian.second_q_op())
```
The resulting Hamiltonian is a weighted sum of operations involving the Pauli operators \(I\), \(X\), \(Y\), and \(Z\). Using known particle-number parities allows the mapper to remove two qubits. QPE needs a starting state. The code builds a Hartree–Fock state, a simple approximation to the molecule’s electronic ground state.
The circuit applies a simulated time-evolution operator
The state acquires a phase determined by its energy. QPE measures that phase, allowing the code to recover the energy.
The circuit does this by:
1. Putting the six evaluation qubits into superposition with Hadamard gates.
2. Applying controlled evolution for times \(t, 2t, 4t, 8t, 16t, 32t\).
3. Applying the inverse quantum Fourier transform to turn the phase information into a binary value.
4. Measuring the evaluation qubits.

The circuit runs 1,000 shots, producing counts for six-bit measurement outcomes. The code chooses the most frequent outcome
 In short: the code builds an electronic energy model, encodes it on qubits, estimates energy through quantum phase measurements, and adds nuclear repulsion to obtain a total molecular energy.
 
#### Music generation
The music is generated by turning random quantum measurement outcomes into notes, then synthesizing those notes as sine waves. It is currently independent of the molecular energy calculation.

The program takes qubits in superposition, measures them 3 times and combines the results position by position. The combined result then determines if the sound becomes pause, lower note, middle note or higher note.
The available notes are A, C-sharp, and E, which together form an A-major chord. Restricting the melody to these related notes helps the random sequence sound harmonically consistent rather than like an unrestricted collection of pitches. Once the note sequence is ready, the program constructs the sound mathematically. It does not use recordings of a piano, guitar, or another instrument.

Each note becomes a sine wave, a smooth, repeating vibration with a single frequency. Faster vibrations produce higher pitches, while slower vibrations produce lower pitches. This gives the audio a simple, pure electronic tone rather than the richer sound of an acoustic instrument.

```
                   │  30 random indices│   │  Indices → tones │   │  9 seconds of      │

                   └───────────────────┘   └──────────────────┘   └────────────────────┘
              
 # created with ai       
   ```

> The pipeline uses PySCF to compute molecular integrals and Qiskit Nature to construct the qubit Hamiltonian and Hartree–Fock initial state. Quantum Phase Estimation (QPE) runs on a quantum backend, either hardware or a simulator, to estimate molecular energies and display a report in the browser.
After QPE completes, separate quantum sampling generates 30 random note indices. sound\.py converts these indices into sine-wave tones and rests, producing nine seconds of audio played through the browser’s Web Audio API. The music is generated from quantum randomness, not from the estimated molecular energies
